# Results shown in the presentation

These tables and figures preserve the original measured results used in the presentation. New runs write to their own directories.

- [FI historical single-run table](fi/summary.csv) transcribes the paper reproduction rows shown in the deck.
- [Spatial FFT summary](fft/summary.csv) keeps clean inputs and the six low-pass cutoffs for the three frozen CE checkpoints. The ECC curve is plotted directly from this table.
- [Haar transform diagnostics](wavelet/wavelet_sp_results.json) preserve all measured sweeps and real-image measurements from the original operator test.
- [Haar recognition seed table](wavelet/seed_results.csv) keeps the two primary arms from the original six-arm study. The [paired table](wavelet/summary.csv) preserves the corresponding original differences, seed intervals, and Holm-adjusted p-values.
